# Куда пойти (Where to Go)

Django-проект с картой интересных мест.  
Локации хранятся в базе, а в админке можно редактировать описания, загружать фотографии и менять их порядок перетаскиванием.

## Запуск

Для запуска нужен Python 3.10+.

1. Установите зависимости:

```sh
pip install -r requirements.txt
```

2. Примените миграции:

```sh
python manage.py migrate
```

3. Создайте администратора:

```sh
python manage.py createsuperuser
```

4. Запустите сервер:

```sh
python manage.py runserver
```

Сайт будет доступен по адресу `http://127.0.0.1:8000/`, админка по адресу `http://127.0.0.1:8000/admin/`.

## Переменные окружения

Часть настроек проекта берётся из переменных окружения через `environs`.

Создайте файл `.env` рядом с `manage.py` и добавьте в него значения по примеру [`.env.example`](.env.example):

- `SECRET_KEY` — секретный ключ Django.
- `DEBUG` — режим отладки (`True` или `False`).
- `ALLOWED_HOSTS` — список разрешённых хостов через запятую.
- `DB_ENGINE` — backend базы данных (по умолчанию `django.db.backends.sqlite3`).
- `DB_NAME` — имя/путь к базе данных (по умолчанию `db.sqlite3`).

## Что есть в проекте

- GeoJSON для карты формируется из БД во `views.py`.
- API деталей локации: `/places/<id>/`.
- Загрузка и раздача картинок через `MEDIA_URL`/`MEDIA_ROOT`.
- В админке:
  - WYSIWYG-редактор (`django-tinymce`) для длинного описания,
  - превью изображений,
  - сортировка картинок drag-and-drop (`django-admin-sortable2`).

## Загрузка данных

Загрузить одну локацию по URL JSON:

```sh
python manage.py load_place "http://адрес/файла.json"
```

Пример, как если у Вас JSON файл находился в папке проекта /media/places_jsons/:

```sh
python manage.py load_place "http://127.0.0.1:8000/media/places_jsons/Антикафе Bizone.json"
```

Пример вывода в консоль:

```text
Загружено место: Антикафе Bizone
```

### Формат JSON для `load_place`

Команда ожидает JSON со следующими полями:

- `title` — обязательное поле, название локации. Если локация с таким названием уже есть в базе, она будет обновлена.
- `description_short` — обязательное поле, краткое описание. Можно передать пустую строку.
- `description_long` — обязательное поле, полное описание. Можно передать пустую строку, HTML допустим.
- `coordinates` — обязательный объект с координатами.
- `coordinates.lng` — обязательное поле, долгота.
- `coordinates.lat` — обязательное поле, широта.
- `imgs` — необязательный список ссылок на изображения. Если список передан, картинки будут скачаны и привязаны к локации по порядку.

Ссылки в `imgs` могут быть абсолютными или относительными. Для относительных ссылок используется базовый URL JSON-файла.

  ],
  "description_short": "Настольные и компьютерные игры, виртуальная реальность и насыщенная программа мероприятий — новое антикафе Bizone предлагает два уровня удовольствий для вашего уединённого отдыха или радостных встреч с родными, друзьями, коллегами.",
  "description_long": "<p>Рядом со станцией метро «Войковская» открылось антикафе Bizone, в котором создание качественного отдыха стало делом жизни для всей команды.</p><p>В Bizone вы платите исключительно за время посещения.
